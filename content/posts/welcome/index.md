Starting this blog mainly to document things I'd otherwise forget. Vulnerability research, CTF solutions, tooling I've built, and whatever else I find interesting enough to write about.

## What I'll post about

- Vulnerability research: interesting bugs, attack vectors, exploitation techniques
- CTF writeups, mostly from TryHackMe and HackTheBox
- Security tooling and automation scripts I build for work and side projects
- Threat modeling and how I approach mapping attack surfaces

No promises on a regular posting schedule.

## About me

Application Security Engineer. I do security assessments on web, cloud, and iOS apps. Done 110+ so far. I also build security tools, design CTF challenges for internal training, and spend probably too much time on HackerOne and Bugcrowd.
