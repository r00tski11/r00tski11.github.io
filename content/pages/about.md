I'm Joel, application security engineer at Zoho, based out of Chennai. Been doing security assessments on web, cloud, and iOS apps for the last 3 years -- 110+ apps so far.

## What I do

Manual testing, code review, and threat modeling (STRIDE). I also build tools to make the repetitive parts of testing easier:

- **iOS IPA Analyzer** -- OWASP Mobile Top 10 rules, uses Shannon entropy for secrets detection
- **CI/CD Supply-Chain Security System** -- Python, FastAPI, PostgreSQL, Ed25519 signatures
- **AWS IAM Security Scanner** -- catches privilege escalation and bad policies
- **OAuth/SAML Security Toolkit** -- for testing SSO flows
- **Web App Vuln Scanner** -- auth bypass, IDOR, SQLi, XSS detection

Tools I use daily: Burp Suite, Frida, Objection, MobSF, Nuclei, ZAP.
